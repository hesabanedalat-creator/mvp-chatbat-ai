# AI Website Chatbot (MVP)

A lightweight AI-powered chatbot for business websites  
(Medical, e-commerce, service-based).

Built for fast deployment and early sales.

---

## Features

- AI chatbot powered by LLM (ChatGPT)
- Answers based on website / business content
- Simple RAG (context injection)
- API-key based multi-customer support
- Embeddable chat widget
- Ready for MVP demos and early customers

---

## Tech Stack

- Backend: FastAPI (Python)
- LLM: OpenAI GPT
- Frontend: Vanilla JS (iframe widget)
- Auth: API Key
- Deployment: Any VPS / Cloud
